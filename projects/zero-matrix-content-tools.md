# zero-matrix-content-tools

> Public project overview. The source repository is private.

A local-first content-production and validation toolchain for **Zero Matrix**, designed to turn structured inputs into reproducible visual outputs while keeping data-quality checks explicit and auditable.

## Engineering highlights

- Structured content as the source of truth
- Schema-based validation and blocker/warning quality gates
- Versioned visual templates
- Deterministic PNG and ZIP generation
- Manifest and SHA-256 based traceability
- Human-verification boundaries around AI-assisted workflows
- Local-first Windows workflow and developer tooling

## Tech

`TypeScript` · `Node.js` · `Zod`

Only this high-level overview is public. The implementation repository, detailed production rules and internal assets remain private.
