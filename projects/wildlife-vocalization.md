# Wildlife Vocalization Monitoring and Identification System

> Public project overview. The source repository is private.

An earlier academic project exploring wildlife vocalization monitoring and species identification using deep learning and a full-stack application workflow.

## Project scope

- Construction and organization of a wildlife vocalization dataset
- Audio-event detection and species-recognition experiments
- Model-serving workflow for audio inference
- Web application for audio upload, recognition results and data management
- Integration between backend services, model inference and frontend presentation

## Tech

`Python` · `FastAPI` · `Spring Boot` · `Vue 3` · `MySQL`
