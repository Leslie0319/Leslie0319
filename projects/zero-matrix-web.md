# zero-matrix-web

> Public project overview. The source repository is private.

The official website project for **Zero Matrix Technology**, implemented as a lightweight static site with a focus on maintainability, responsive design and deployment simplicity.

## Engineering highlights

- Static-site architecture
- Responsive desktop and mobile layouts
- Production build and deployment workflow
- SEO, accessibility and launch QA considerations
- Separation between public website code and internal company source-of-truth materials

## Tech

`Astro` · `TypeScript` · `Cloudflare Workers` · `GitHub Actions`

Only this project overview is public. The source repository and internal implementation details remain private.
