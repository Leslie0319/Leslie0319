# zero-matrix-finance-content

> Public project overview. The source repository is private.

A versioned content-standards repository for **Zero Matrix** financial-content workflows. It defines reusable rules, validation requirements, source-verification expectations and release conventions across multiple recurring content formats.

## Engineering highlights

- Versioned content standards and prompt specifications
- Machine-readable routing and configuration
- Data freshness and source-verification gates
- Reusable workflow rules across multiple content categories
- Release checks, manifests and change tracking
- Shared specifications for downstream content-generation tooling

The private repository contains detailed operational rules, historical examples and internal production standards. This page exposes only a high-level technical overview.
